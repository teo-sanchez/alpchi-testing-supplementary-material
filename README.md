Exploring people's testing strategies in ML-based image classification (AlpCHI 2026)
=================================================
Code and data to reproduce the paper **Exploring people’s testing strategies in ML-based image classification** Proceedings of AlpCHI 2026. [DOI: 10.1145/3780045.3780051](https://doi.org/10.1145/3780045.3780051).


Citation
-----------------
If you cite this code or data, please cite the following publication:
```
Sanchez, T., Kalamara F.M., Stumpf, S., Caramiaux, B. (2026). Exploring people’s testing strategies in ML-based image classification. Proceedings of the 1st AlpCHI conference 2026. DOI: 10.1145/3780045.3780051
```

Repository structure
-----------------
- `data_analysis/` – Data and code for the analysis and figure generation, reproducible in Jupyter Notebooks.
- `docs/` - Contains post-task questionnaire and instructions used in the user study.
- `conda_requirements.txt` – reproducible environment spec (Python 3.11).
- `experimental_prototype/` - Code for the experimental prototype used in the user study, build with [Marcelle](https://marcelle.dev/).
